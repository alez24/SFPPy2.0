#   pip install -r survey/requirements.txt
#

#   pip install -e ".[survey]"
#
# Alternative installation methods:
#   - Root environment.yml        (conda, full installation)
#   - survey/environment.yml      (conda, survey-specific)
#   - requirements/survey.txt     (modular pip requirements)
#   - docker/docker-compose.yml   (Docker deployment)
#
# Launch applications:
#   python survey/launcher.py              # Both apps (ports 8000, 8001)
#   python survey/launcher.py --app editor # Family Editor only (port 8000)
#   python survey/launcher.py --app simulator # Simulator only (port 8001)
